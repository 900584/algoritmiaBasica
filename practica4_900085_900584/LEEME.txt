========================================
1) Organizacion del directorio
========================================
- LEEME.txt: este fichero.
- Makefile: compilacion de los programas C.
- ejecutar.sh: script bash para compilar, ejecutar y validar todas las pruebas.
- ejecutar_windows.ps1: equivalente al anterior para PowerShell (Windows).
- informe.md: informe completo (Tareas 1-4 y Conclusiones).
- src/formarEquipos.c: programa principal (ramificacion y poda, Tarea 2).
- src/verificar_bruteforce.c: validador exacto por fuerza bruta (N pequenos).
- src/resolverLP.py: solucion ILP con PuLP/CBC (Tarea 4).
- pruebas/pruebas.txt: casos de validacion funcional (N=6, N=9).
- pruebas/experimentos.txt: casos de experimentacion (N=12, N=15, N=18).
- resultados/: salidas generadas por ejecutar.sh / ejecutar_windows.ps1.

========================================
2) Requisitos
========================================
Para las Tareas 1-3 (Branch&Bound):
- Compilador C compatible con C11 (gcc recomendado).
- make

Para la Tarea 4 (Programacion lineal):
- Python 3.8 o superior.
- Libreria PuLP (incluye el solver CBC):
    pip install pulp

========================================
3) Instalacion / compilacion
========================================
Desde el directorio practica4:

  make

Esto genera:
- formarEquipos (o .exe en Windows)
- verificarBruteforce (o .exe en Windows)

Para limpiar binarios y resultados:

  make clean

========================================
4) Ejecucion
========================================
Ejecucion manual de Branch&Bound:

  ./formarEquipos pruebas/pruebas.txt resultados/resultados_pruebas.txt

Ejecucion manual de ILP:

  python3 src/resolverLP.py pruebas/pruebas.txt resultados/resultados_pruebas_lp.txt

Formato general:

  ./formarEquipos <entrada.txt> <salida.txt>
  python3 src/resolverLP.py <entrada.txt> <salida.txt>

========================================
5) Repeticion de pruebas
========================================
La forma recomendada de repetir todo:

  En Linux/Mac:
    chmod +x ejecutar.sh
    ./ejecutar.sh

  En Windows (PowerShell):
    .\ejecutar_windows.ps1

El script realiza los siguientes pasos:
1. Compila los programas C.
2. Ejecuta Branch&Bound sobre pruebas y experimentos.
3. Ejecuta el verificador por fuerza bruta en pruebas pequenas.
4. Compara automaticamente BnB con fuerza bruta.
5. Ejecuta el solver ILP (Tarea 4) sobre pruebas y experimentos.
6. Compara automaticamente BnB con ILP.

========================================
6) Notas
========================================
- El programa principal soporta N <= 63 (mascara de bits de 64 bits).
- El verificador por fuerza bruta esta pensado para N <= 12 aprox.
- El ILP (resolverLP.py) no tiene limite de N practico para los rangos
  considerados; con N=18 resuelve en < 65 ms.
- PuLP usa el solver CBC de COIN-OR (incluido en el paquete pip).
